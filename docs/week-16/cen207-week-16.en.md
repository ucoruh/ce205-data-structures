# Week 16 — Final Exam Period: Quiz-2

*CEN207 Data Structures (formerly CE205) · Fall 2026–2027 · 04–17.01.2027*

**Quiz-2** covers weeks 9–14 and is 30% of the final grade (the final project RAP2 is the other 70%).

| Week | Topics to review |
| --- | --- |
| 9 | Graph algorithms: MST (Prim, Kruskal), shortest paths (Dijkstra, Bellman–Ford), SCC, max flow, cycle detection, backtracking |
| 10 | Sorting algorithms and their comparison |
| 11 | BST, AVL, red-black, splay and B-tree family |
| 12 | String search (KMP, Boyer–Moore), LCS, edit distance, alignment, tries |
| 13 | File organisation I: sequential and direct files, collision resolution |
| 14 | File organisation II: indexed files, B-trees for files, extendible hashing, external sorting |
